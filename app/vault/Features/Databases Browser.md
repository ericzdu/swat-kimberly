# Databases Browser

The [[SWAT+ Editor]]'s **Databases** section opens the reference databases as searchable, paginated, sortable tables — with per-row edit and delete.

## Files
- `plants.plt` — plant growth database (**266 species × 54 parameters**; `plnt_typ` renders as a dropdown: warm/cold-season annual, perennial, tuber, tree)
- `fertilizer.frt` — fertiliser N/P fractions (relevant to nitrate)
- `tillage.til`, `pesticide.pes`, `urban.urb`, `septic.sep`, `snow.sno`

## UX
The `FileTableEditor` list view provides a search box, "N rows · M cols", pagination (50/page), column sort, and per-row edit → a [[Structured Record Forms|record form]].
